# Shanghai travel website

Read and follow `AGENTS.md` and `README.md` in this repository.

This public GitHub repository is the editing source for the travel site https://ingunbi.github.io/shanghai-tech-2026/. Modify the static files under `dist/`; the trip is in `dist/data-public.js`. Preserve the concise layout, short travel routes, and consistent itinerary/map/video dates.

Run `node scripts/validate-public-site.mjs` and check the changed screen. A relevant push or merge to `main` publishes through **Publish Shanghai site** (GitHub Pages). Check the workflow result and the live page before claiming it is live. Use a branch/PR if review is requested.

Do not create another site/repository or mirror, or expose booking references, personal information (including personal phone numbers) or credentials. The repository is public.
